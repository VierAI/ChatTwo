# Chat 2 (VierAI-fied) changelog

Cumulative list of changes from upstream Chat 2. Updated as changes land.

## Features

- Blended line background and split fade (1.41.2.10): the backgrounds behind bright new lines are now drawn together as one shape per run of lines, so where lines or messages meet they blend instead of overlapping and getting darker (most visible when Window opacity is below 100%); only the outside of a run has the soft edge. The background is centred on the actual letters (from the top of capitals to the bottom of p, j, g and y), so the gap above and below is equal, and in the timestamp layout it covers the timestamp and the message together. The unfocused opacity is now two settings in Settings > Chat log: Window opacity (unfocused) for the window itself (background, buttons, tabs, input) and Line opacity (unfocused) for the message lines, so the lines can stay more readable while the window fades further. Existing settings start both at your current unfocused value (AI generated code)
- Softer line background (1.41.2.9): the background behind bright new lines now has a soft edge that fades out over a few pixels, sits a pixel lower so letters like p, j, g and y clear the bottom, and has a new setting, Settings > Chat log > Bright line background max opacity (default 60%, 0 turns it off), to make it more see-through. The setting is saved as soon as you change it (AI generated code)
- Line background follows the text (1.41.2.8): the background behind bright new lines now only covers the text on each line (wrapped lines included, plus the timestamp), with a little padding and rounded corners, instead of the full window width, so it blocks as little of the game as possible (AI generated code)
- Fade fixes (1.41.2.7): new lines that are still brighter than the faded window now get their own background behind the row, so they stay readable over a light scene; it shows with the line and fades with it. Window opacity and the fade settings now take effect and are saved as soon as you let go of a slider or enter a value, so a change is no longer lost when the settings window is closed without pressing Save (AI generated code)
- Slower new-line fade (1.41.2.6): the new message setting is now the total fade time. A new line stays at full opacity for the first half, then fades smoothly (smoothstep curve, by the line's age) down to the window opacity over the second half, instead of dropping almost at once. It is never dimmer than the window. The default is now 20 s (10 s solid, then 10 s fading); a value already saved in your settings is kept. Typing a value with Ctrl+click on the opacity and fade sliders is no longer fought by the range check (values are still kept in range once you finish) (AI generated code)
- Window fade background fix (1.41.2.5): with the fade on, the window background now fades with the text (to the focused opacity times the unfocused opacity; at 0% it is fully transparent, so only bright new lines show). Before, Dalamud's background alpha override kept it solid (AI generated code)
- Fade settings as sliders (1.41.2.5): Window opacity, unfocused opacity, fade speed per frame and new message delay in Settings > Chat log are now sliders with a track and grab (Ctrl+click to type a value); values stay in range (AI generated code)
- Scrolled-up log holds its place (1.41.2.5): when the log is full and old lines drop off the top, a log you scrolled up to read stays on the same lines instead of scrolling by; once those lines reach the top of the buffer they scroll off as before. At the bottom nothing changes (AI generated code)
- Window fade (1.41.2.4): optional, off by default. Settings > Chat log > Fade the chat window when not in use. While the mouse is away and you are not typing, the main chat window eases down to an unfocused opacity at an adjustable per-frame speed and eases back when you hover, type or open a menu. New lines stay at full opacity for an adjustable number of seconds, then fade one at a time. The existing Window opacity slider is the focused opacity (AI generated code)
- Based on Chat 2 1.41.2 (1.41.2.1): includes the upstream 1.41.2 change (keybinds are no longer checked while in keybound brawler mode); all VierAI-fied features unchanged
- Based on Chat 2 1.41.1 (1.41.1.1): includes the upstream 1.41.1 changes (keybound brawler fix, removed old migration paths, translation updates); all VierAI-fied features unchanged
- Rich chat input (1.40.9.27): the chat input now uses RichChatInput, a small MIT-licensed input editor shared with the VierAI-fied XIM (source copy in ChatTwo/RichChatInput). Long messages wrap onto up to 4 lines instead of scrolling sideways (Settings > Chat Log, on by default; Up/Down then recall history only on the first or last line); triple-click selects the whole message; Shift+click extends the selection; Ctrl+Delete deletes the word to the right (Ctrl+Backspace to the left as before); Ctrl+Z undoes and Ctrl+Y or Ctrl+Shift+Z redoes, typing in word-sized steps; right-click gives Cut, Copy, Paste and Select All (plus Hide chat; on a misspelled word the spelling suggestions come first); a selection can be dragged with the mouse to move it, or copied when Ctrl is held on release; a half-typed message is kept when the window is closed or the plugin reloads; the 1.40.9.26 double-click word drag is now part of the editor. The length bar is drawn by the editor and from 80% shows the byte count (used/500). Enter, channel prefixes, Tab completion, auto-translate blocks, spell check, IME, keybinds and the jump to the newest message are unchanged (AI generated code)
- Word-by-word drag selection (1.40.9.26): double-click a word in the chat input and keep the left button down; dragging then selects whole words (a run of spaces or of punctuation counts as one step) to the left or right of that word, and the double-clicked word stays selected even when the drag comes back across it. Releasing the button ends it. Single-click caret placement, normal click-drag selection, Shift+click, Shift+arrows, copy/paste, Enter, auto-translate blocks, the length bar and the jump to the newest message are unchanged; main window and popped-out tabs (AI generated code)
- Message log follows typing (1.40.9.25): clicking into the chat input, typing or editing in it (held keys repeat, paste and delete count) and sending with Enter jump the message log to the newest message, in the main window and in popped-out tabs. Modifier keys alone, Esc, F-keys and Page Up/Down do not. A log you scrolled up to read is left where it is while you are not typing, and the usual stick-to-bottom while at the bottom is unchanged (AI generated code)
- Message length bar (1.40.9.22, colours 1.40.9.24): a thin bar under the chat input fills as you type, counting the UTF-8 bytes of the line that will be sent (channel prefix such as /s or /tell Name@World included) against the game's 500-byte limit for one chat line. It stays plain white up to 250 bytes (50%), fades to yellow by 375 bytes (75%) and to red by 450 bytes (90%), and stays red past 500; hover over it for the exact count. Shown in the main window and in popped-out tabs. Toggle in Settings > Chat Log, "Show the message length bar" (on by default) (AI generated code)
- Right-click only menu (1.40.9.21): left-click on a message no longer opens the context menu; it only selects text. Links, map links, quests, achievements, party finder and plugin links still act on a plain left-click. Items, player names and plain text open their menu on right-click only, with the same entries as before, Copy link and Copy selection included (AI generated code)
- Character-level selection and Copy link (1.40.9.20): a drag now selects from the exact character under the mouse, within one line or across lines and messages, so part of a line (one web address out of several) can be copied. Right-click on a web address shows Copy link for that address only, even with several on one line. Ctrl+C on a selection no longer reaches the game (it opened the currency window). Links, item links and party finder links still open on a plain click (AI generated code)
- Drag to select and copy (1.40.9.18): press on or near message text and drag to select one or more lines (wrapped lines included), then Ctrl+C or right-click > Copy selection to copy them as plain text; Escape or a click clears it. A plain click still opens links, item links and party finder links; dragging empty space still moves the window (when moving is allowed). Toggle in Settings > Display (on by default)

- Send Tell opens XIM: when XIM is installed and loaded, Send Tell on a player name opens that player's XIM conversation with its input focused instead of typing /tell in Chat 2; falls back to /tell otherwise; toggle in Settings > Chat Log (on by default)
- Scroll-to-bottom button: when you scroll up in the message log, a small down-arrow button appears in its bottom-right corner; click it to jump back to the newest message
- Spell checker in the chat input: misspelled words are highlighted, hover or right-click for suggestions, Add to dictionary or Ignore; skips commands, links, auto-translate, numbers, ALL CAPS and nearby player names; includes an FFXIV word list; toggle in Settings > Chat Log
- Spell check settings: Highlight, Wavy or Straight style, colour, highlight fill slider, hover suggestions on/off, Clear ignored words; ignored words and the user dictionary are shared between the VierAI-fied XIM and Chat 2 (vierai-config.json)
- Up/Down recalls earlier messages and commands; one history for all input boxes, saved between restarts and shared with the VierAI-fied XIM; Down past the newest entry restores your draft
- Tab completion fills in the command straight away when there is only one match that starts with what you typed (fixed in 1.40.9.12: it used to flicker and revert); otherwise the auto-translate search window opens as before
- Auto-translate phrases show in the input as the words between the game's auto-translate arrows, like the vanilla chat box, instead of a raw <at:..> code; they are still sent as real auto-translate
- Auto-translate phrases in the input act as one block: the cursor cannot land inside one, Backspace or Delete on any part (including either arrow) removes the whole phrase, and a selection that touches one covers all of it
- Handles the Shout (always) game keybind; /chat2keys lists the chat keybinds read from the game
- The plugin installer's main window button now shows the chat window if it is hidden
- Installs as its own plugin (ChatTwoVierAIfied), imports the official Chat 2 settings on first start and shares the official message database

## Fixes

- Spell check suggestion popup stays on screen: when the input is near the bottom of the screen it opens above the word instead of below, and it is always kept inside the game window, left and right too (AI generated code)

- Tab completion of emotes and text commands inserted a code like <at:62,504> instead of the command
- More responsive typing: typed characters no longer wait in the one-key-per-frame queue, so fast typing and frame hitches no longer delay or drop letters; editing keys and shortcuts (Backspace, Enter, arrows, chords) stay queued so a tap still registers
- A message arriving at the same moment the message queue emptied could be lost; it is now always picked up
- Uses its own message database for the session when the official Chat 2 is loaded too (no duplicate messages or database locks)
- The input history shared with XIM is saved safely when both plugins write at once

## Performance

- Keybind lookups are spread across frames (a few per tick, refreshed every 5 s) instead of one framework spike
- The message processing thread sleeps until a message arrives instead of waking every millisecond
- The key list used to release keys while typing is built once instead of on every keypress
- Hide vanilla chat (1.40.9.19): the five chat-window lookups no longer run every frame; once all are hidden the result is reused for 250 ms, and a zone change or login re-checks on the next frame
